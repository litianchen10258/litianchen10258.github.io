# Pixiv 爬取工具

## 使用方法

1. 把要下载的作品链接填进对应列表文件（一行一个）：
   - 小说：打开 `pixiv_urls.txt`，粘贴小说链接
   - 漫画：打开 `pixiv_manga_urls.txt`，粘贴作品链接
2. 双击运行：
   - 下载小说：双击 `下载小说.bat`
   - 下载漫画：双击 `下载漫画.bat`

脚本会自动下载列表里的全部作品，完成后自动结束窗口。

## 文件说明

| 文件 | 作用 |
|------|------|
| `下载小说.bat` | 一键批量下载小说 |
| `下载漫画.bat` | 一键批量下载漫画 |
| `pixiv_urls.txt` | 小说链接列表，每行一个 |
| `pixiv_manga_urls.txt` | 漫画链接列表，每行一个 |
| `pixiv_cookies.txt` | 登录凭证，需要先填好 |
| `爬取日志.txt` | 自动生成，记录每次下载结果 |

## 第一次使用前：填 cookie

1. 浏览器打开 [pixiv.net](https://www.pixiv.net) 并登录
2. 按 F12 → Application → Cookies → `pixiv.net`
3. 找到 `PHPSESSID`，复制 Value 列的完整值
4. 打开 `pixiv_cookies.txt`，改成：
   ```
   PHPSESSID=粘贴你复制的那串值
   ```
5. 保存文件即可，之后不用再改

## 下载结果

- 小说：生成 `.docx` 文件，直接放在本文件夹
- 漫画：生成 `标题_作品ID/` 文件夹，里面是每页图片

## 常见问题

- 列表里某个链接下载失败：先确认链接里 ID 正确、该作品未被删除
- 全部下载失败：多半是 `pixiv_cookies.txt` 没填对或已过期，重新获取一次
